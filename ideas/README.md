# Ideas

One file per idea. Numbered, kept even when we decide against them — a rejected idea with
the reasoning attached is useful, and a couple of these are worth building after the
hackathon regardless.

## Adding yours

1. Copy `_TEMPLATE.md` to `NNN-short-name.md`, next number up.
2. Fill it in roughly. Fifteen minutes, not an hour.
3. Run the pressure-test prompt from `docs/WORKING-WITH-AI.md` against it and write the
   honest answers into the *Four questions* and *Known weaknesses* sections.
4. Post it in the channel.

An idea with weaknesses named beats one that looks flawless because nobody looked hard.
